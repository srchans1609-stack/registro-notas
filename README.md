# Registro de Notas - Práctica 2 Arrays

## Funciones que CAMBIAN la lista original (Transforman el array)
* `anadirAlumno`
* `quitarUltimo`
* `insertarEn`
* `borrarPorNombre`

## Funciones que NO CAMBIAN la lista (Devuelven copias o datos)
* `buscarPorNombre`
* `ordenarPorNota`
* `ordenarPorNombre`
* `notaMedia`
* `notaMaxima`
* `aprobados`
* `nombresAprobados`
* `hayAlgunDiez`
* `todosAprobados`
* `ranking`
* `filtrarAlumnos`
* `ordenarAlumnos`
